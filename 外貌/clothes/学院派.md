# 造型一：轻复古学院派

> **场合：** 上学、去图书馆、和朋友约在咖啡馆
>
> **整体气质：** 干净、安静、有点书卷气，像是会坐在窗边看书的女孩。少女感来自剪裁和配色，而不是露肤或夸张装饰。

- **定位：** 两套独立造型之一，是「出门面对世界」的版本。
- 另一套见 [`森系软妹.md`](森系软妹.md)，总览与切换逻辑见 [`../clothes.md`](../clothes.md)。

---

## 单品清单

| 部位 | 单品 | 细节 |
| --- | --- | --- |
| 上身 | 娃娃领衬衫 | 小圆领，领口有刺绣小花或小猫图案，袖子微微蓬起 |
| 叠穿 | 菱格针织背心 | V 领，短款，藏青或深棕色，菱格纹不要太密 |
| 外套 | 牛角扣大衣 | 米白／燕麦色，长度到膝盖上方，牛角扣是深棕色 |
| 下身 | 毛呢百褶裙 | A 字型，长度到膝盖下方，深棕或墨绿，和背心同色系 |
| 鞋 | 圆头玛丽珍鞋 | 深棕色，一根搭扣，鞋头有点圆润 |
| 袜子 | 堆堆袜 | 米白色，松松垮垮堆在脚踝，故意不配对（左脚纯色，右脚有细条纹） |

---

## 配饰与细节

| 部位 | 内容 |
| --- | --- |
| 发饰 | 一侧麻花辫上别小猫发夹（银色或浅金色，小巧不夸张），另一侧发尾绑深棕色丝带 |
| 包 | 帆布书包，米白色，包身别着两三个徽章（一个猫爪、一个星星、一个朋友送的），拉链上挂着毛绒小猫挂件 |
| 手腕 | 褪色的编织手绳（朋友送的，戴了很久） |
| 口袋 | 书包侧袋露出一小截猫粮袋，大衣口袋里塞着揉皱的纸条（记着要帮朋友带的东西） |

---

## 配色方案

米白 + 燕麦 + 藏青 + 深棕 + 一点点干枯玫瑰粉（袜子或发绳）

色号见 [`../colours/colour_of_学院派.md`](../colours/colour_of_学院派.md)，通用色见 [`../colours.md`](../colours.md)。

## 性格解读

- 娃娃领 + 背心 + 百褶裙的组合让她看起来「乖巧」，但袜子不配对、包上徽章乱别，暴露了她的迷糊和真实。
- 牛角扣大衣是被保护感的视觉符号——让人想帮她把扣子扣好。
- 小猫发夹是她唯一「主动展示」的可爱，其他细节都是不经意流露的。
- 整体不修身、不紧绷，符合她内敛不张扬的气质。
