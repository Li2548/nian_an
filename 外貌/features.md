# 面部特征与身材细化（适合绘图）

身高设定为 **160cm**。以下按「面部 → 五官 → 头发 → 身材 → 表情与姿态 → 绘图提示」拆解，所有描述尽量使用可画的视觉语言，可直接交给画师或用于起稿。

- 已有锚点：白色偏粉长发、低双麻花辫松散编成、头顶一缕不听话的呆毛、灰蓝色眼睛、笑起来左脸颊有浅浅酒窝、校服上总别着一个小猫形状的徽章。

## 六、绘图提示汇总

> **面部：** 鹅蛋脸、圆下巴、脸颊微肉；圆杏眼、眼尾微垂、眼距稍宽、窄双、灰蓝虹膜、双高光；低鼻梁、圆鼻头；小唇、自然粉；左脸颊浅酒窝。
>
> **头发：** 白粉长发 `#F2E8E8`，发尾渐粉 `#EED9DD`，蓬松微卷；微偏分；头顶偏左问号形呆毛；无刘海，额前碎发到颧骨；低双麻花辫松散编，耳后下方起始，发尾留散；左侧第三交叉点别银色小猫发夹 `#C0C0C0`，右侧发尾绑带。
>
> **身材：** 160cm，6.5头身，窄肩溜肩，小骨架，细腕细踝，胸适中偏小，高腰线，臀适中，腿直匀称，36码窄脚，手指修长。
>
> **气质：** 安静、柔和、内敛，笑起来有酒窝和月牙眼，害羞时耳朵先红，遇到猫会蹲下缩成团。
