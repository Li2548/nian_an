# 两套造型颜色色号细化

下面按「角色基础色 → 学院派造型 → 森系造型 → 共享元素」来列。所有色号均为 HEX，方便绘画、建模或设计时直接取用。实际使用时可根据光线和媒介微调。

两套造型各自的色号已拆到单独文档：

| 造型 | 文档 |
| --- | --- |
| 轻复古学院派 | [`colours/colour_of_学院派.md`](colours/colour_of_学院派.md) |
| 森系软妹 × 手作感 | [`colours/colour_of_森系软妹.md`](colours/colour_of_森系软妹.md) |

## 一、角色基础色（两套通用）

| 部位 | 颜色 | 色号 | 说明 |
| --- | --- | --- | --- |
| 肤色 | 冷白偏暖 | `#F8E8E2` | 不会太苍白，有血色感 |
| 脸颊红晕 | 淡粉 | `#F4C2C2` | 害羞或冷的时候会更明显 |
| 嘴唇 | 柔粉 | `#E8A0A0` | 不涂口红，自然血色 |
| 头发基底 | 白偏粉 | `#F2E8E8` | 远看是白，近看有粉调 |
| 发尾渐变 | 浅粉 | `#EED9DD` | 从耳下开始微微变粉 |
| 头发高光 | 暖白 | `#FFF5F7` | 阳光下会泛一点粉光 |
| 呆毛 | 同基底 | `#F2E8E8` | 发尾可带一点 `#EED9DD` |
| 眼睛虹膜 | 灰蓝 | `#8FAEC4` | 温和、有深度，不刺眼 |
| 眼睛瞳孔 | 深灰蓝 | `#3A4A5A` | 让眼神显得安静 |
| 眼睛高光 | 冷白 | `#E8F0F5` | 笑起来会弯成月牙 |
| 睫毛/眉毛 | 浅灰棕 | `#B8A8A0` | 和发色协调，不突兀 |
